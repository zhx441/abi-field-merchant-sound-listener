# 38 组音效逐组召回测试

测试日期：2026-09-25。每组各测拾起、放下两段参考音效，共 76 段；分别混入四种固定种子的模拟背景，合计 304 次。表中每格顺序为“拾起 / 放下”；✓ 表示识别到正确声音组且达到自动模式的单次判定阈值，✗ 表示未达到。自动显示还需连续两次相同候选。

这些是**参考音效混音测试**，尚未包含用户机器上录制的真实游戏背景音乐、音量设置、声卡处理和其他游戏音效，不能当作实际游戏的召回率。
